# Customer Segmentation

Group customers by behaviour (recency, orders, spend) using K-Means.
This helps marketers target VIPs, regular buyers and at-risk customers in different ways.

**Data:** sample (synthetic). No real customer data.

## Run it

```
pip install pandas numpy matplotlib scikit-learn
python segment.py
```

Outputs: `segment_summary.csv` and `segments.png`.

## Idea for each segment

- High spenders: loyalty perks and early access
- Middle group: upsell and cross-sell
- Inactive customers: win-back offers
